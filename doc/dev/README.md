# dev

What's open, what's still to be decided, and what has been — rather than a
description of the repo as it is (that's the folder above).

- `todo.md` — the open work, one box per item.
- `decision.md` — the decision log: every choice that took real thought,
  with the options, the tradeoffs, and why the winner won.
- `map.md` — the two-way survey of what could still cross between Julia and
  C, with mapping proposals for the important items.
