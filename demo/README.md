# demo

Worked examples that show what the transpiler does, for people deciding
whether to use it. Nothing here is a test — `test/` proves it works; this
folder shows it off. Each example is a small Julia file that reads as a
physicist or engineer would write it, the C it produces, checked in so it
can be read without running anything, and a few lines on what to look at.

Nothing is here yet; the candidates are in the repo's `todo.md`.
